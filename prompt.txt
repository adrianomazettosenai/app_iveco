PROMPT MASTER — ECOFICINA IVECO 2.0
Crie uma versão aprimorada, profissional e de alta fidelidade do
aplicativo mobile ECOFICINA IVECO, utilizando a imagem de referência fornecida
como base visual.
O aplicativo deve funcionar como uma plataforma inteligente de inspeção de
caminhões, análise de peças, gestão de estoque, troca de componentes entre
unidades IVECO, reaproveitamento e descarte sustentável de resíduos.
O conceito central é:
“Transformar descarte em desempenho.”
A plataforma conecta técnicos + unidades IVECO + estoque de peças +
diagnóstico por IA + empresas de reciclagem/descarte sustentável em um
único ecossistema.

32. CONCEITO PRINCIPAL DO PRODUTO
O aplicativo não deve parecer apenas um scanner.
Ele deve transmitir que é uma rede inteligente de economia circular da IVECO.
A lógica central da plataforma deve ser:
IDENTIFICAR → ANALISAR → DECIDIR → REUTILIZAR → COMPARTILHAR →
RECICLAR
Sempre que uma peça puder ser reaproveitada, o sistema deve priorizar
essa alternativa antes de recomendar descarte.
Quando não houver possibilidade de reaproveitamento, o sistema deve direcionar
o material para uma empresa especializada e permitir o agendamento completo
da coleta.

Não descaracterizar a interface da imagem de referência.

IVECO + IA + Manutenção + Estoque + Compartilhamento + Economia Circular
